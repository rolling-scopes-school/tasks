# 🎓 RS School. Fullstack Engineering Course

## 🚀 Обзор

- 📣 **Открыт для всех, кто хочет присоединиться**
- 📅 **Длительность:** 12 недель (Часть 1 из двух; Часть 2 — на TypeScript)
- 📚 **Формат:** самостоятельное изучение + вебинары + парная/групповая работа + Discord + cross-check
- 🤖 **AI:** AI-ассистенты разрешены, использование должно быть прозрачным
- 🗣️ **Язык курса:** русский

### 📝 Темы курса

- Git, GitHub и вёрстка адаптивных страниц по макету
- Основы JavaScript: DOM, события, встроенные методы строк, чисел и массивов
- Хранение данных в браузере: localStorage и IndexedDB
- Поиск и исправление ошибок в чужом коде, инструменты разработчика
- Unit-тесты и основы TDD
- Алгоритмы и структуры данных: стек, очередь, связный список, дерево
- Работа с внешним API и асинхронные запросы
- Свой сервер: routes, middleware, аутентификация по токену
- Совместная разработка в общем репозитории и парная работа над проектом

---

## 🛠️ Необходимые базовые знания

- В идеале — базовые HTML/CSS/JS
- Но если готовы уделять курсу 30+ часов в неделю, можно стартовать и с нуля

## Программа обучения

### Неделя 1

- Задачи:
  - [CV Project](tasks/cv/README.md) — собрать и задеплоить резюме через Git/GitHub Pages
  - RS-тест «Как учиться в комьюнити» — формат обучения, cross-check
- Стек: Markdown, HTML, CSS, Git, GitHub Pages
- Чему научатся: базовый git-flow, деплой; с первого дня — культура и правила школы

### Неделя 2

- Cross-check:
  - Cross-check проекта [CV Project](tasks/cv/README.md)
- Задачи:
  - [Landing Page. Часть 1](tasks/landing-page/README.md) — адаптивная вёрстка лендинга по макету Figma
- Стек: HTML, CSS (Flex/Grid), Figma
- Чему научатся: semantic HTML, responsive design

### Неделя 3

- Cross-check:
  - Cross-check проекта Landing Page. Часть 1
- Задачи:
  - [Landing Page. Часть 2](tasks/landing-page/README.md) — интерактив (попапы, слайдеры, бургер-меню) + localStorage/IndexedDB
- Стек: JS, DOM API, localStorage, IndexedDB
- Чему научатся: DOM-события, два разных браузерных хранилища данных

### Неделя 4

- Cross-check:
  - Cross-check проекта Landing Page. Часть 2
- Задачи:
  - [Пак JS-задач по базовым методам строк/чисел/массивов](tasks/js-basic-methods/README.md) _(конкретный набор — TBD)_
- Стек: JS
- Чему научатся: методы строк, чисел и массивов

### Неделя 5

- Задачи:
  - [Bug Hunting](tasks/bug-hunting/README.md) — готовые сайты с багами в HTML/CSS/JS, нужно найти и исправить
- Стек: HTML, CSS, JS, DevTools
- Чему научатся: чтение чужого кода, отладка, DevTools

### Неделя 6

- Cross-check:
  - Cross-check проекта Bug Hunting
- Задачи:
  - [Testing intro](tasks/testing-intro/README.md) — часть 1: unit-тесты к готовым функциям; часть 2: функции по готовым тестам (TDD)
- Стек: JS, Jest
- Чему научатся: как писать unit-тесты, чтение тестов как спецификации, TDD

### Неделя 7

- Задачи:
  - [Data Structures & Algorithms](tasks/data-structures-algorithms/README.md) (базовый уровень) — реализовать стек, очередь, связный список, дерево и решить задачи с ними
- Стек: JS
- Чему научатся: основы алгоритмов и структур данных

### Неделя 8

- Cross-check:
  - Cross-check проекта Data Structures & Algorithms
- Задачи:
  - [Работа с готовым веб API](tasks/external-api/README.md) — запросы, рендер данных, обработка ошибок и загрузки
- Стек: JS, fetch/async-await, DOM
- Чему научатся: асинхронная работа с сетью, обработка ошибок API

### Неделя 9

- Задачи:
  - [Каталог веб-игр](tasks/games-catalog/README.md) — общий репозиторий, каждый студент добавляет свою игру
- Стек: JS, Git (совместная работа, PR, merge conflicts)
- Чему научатся: работа в общем кодовом репозитории, разрешение конфликтов слияния

### Неделя 10

- Задачи:
  - [Свой backend](tasks/own-backend/README.md) — сервер с несколькими роутами и middleware для проверки токена из cookies
- Стек: Node.js (http/Express), cookies, middleware
- Чему научатся: серверные роуты, паттерн middleware, базовая аутентификация по токену

### Неделя 11–12

- Cross-check:
  - Cross-check проекта "Свой backend"
- Задачи:
  - [Онлайн-магазин](tasks/online-store/README.md) (парное задание) — каталог, корзина, фильтры; можно опираться на сервер с недели 10
- Стек: JS, DOM/UI по выбору пары
- Чему научатся: парная разработка крупного проекта, распределение зон ответственности, code review внутри пары
