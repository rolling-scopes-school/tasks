# JS Basic Methods

## Навыки

`JavaScript` `String` `Number` `Array` `встроенные методы` `Jest` `Codewars`

## Что делать

Нужно реализовать четыре готовых набора задач на встроенные методы чисел, строк и массивов, а также логику условий и циклов, плюс решить набор задач на [Codewars](https://www.codewars.com/).

Каждый из четырёх наборов — отдельный репозиторий с заготовками функций и Jest-тестами; задача — заставить все тесты стать зелёными.

- [Core JS Numbers](https://github.com/rolling-scopes-school/core-js-numbers) — 37 функций: округление, преобразование чисел в строку и обратно, простые числа, тригонометрия, случайные числа и другие операции с числами.
- [Core JS Strings](https://github.com/rolling-scopes-school/core-js-strings) — 28 функций: пробелы, подстроки, палиндромы, шаблонные строки, ROT13, парсинг e-mail и другие операции со строками.
- [Core JS Arrays](https://github.com/rolling-scopes-school/core-js-arrays) — 30 функций: фильтрация, дедупликация, многомерные массивы, разбиение на чанки, сортировка и другие операции с массивами.
- [Core JS Conditions & Loops](https://github.com/rolling-scopes-school/core-js-conditions-n-loops-tasks) — 15 функций: конвертация в римские числа, спиральная матрица, поворот матрицы, сортировка и другие задачи на условия и циклы **без использования** встроенных методов `String`/`Array`/`Math`.

Отдельно — список задач на Codewars, см. раздел «Задачи на Codewars» ниже.

## Как сдавать

- Каждый из четырёх репозиториев сдаётся отдельно через авто-тест в [RS App](https://app.rs.school/): открыть вкладку `Auto-Test`, выбрать нужное задание (`Core JS Numbers` / `Core JS Strings` / `Core JS Arrays` / `Core JS Conditions-n-loops`) и нажать «Submit».
- Задачи на Codewars сдаются одним общим авто-тестом: вкладка `Auto-Test` → выбрать `Codewars` → указать свой никнейм на Codewars → «Submit».

Пересдавать можно сколько угодно раз до дедлайна — каждая следующая попытка перезаписывает предыдущую.
