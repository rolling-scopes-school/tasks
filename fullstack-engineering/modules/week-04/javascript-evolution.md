# JavaScript. Эволюция

## Обзор модуля

В модуле «JavaScript. Эволюция» студенты познакомятся с современными возможностями и улучшениями, появившимися в ES2015 (также известном как ES6), и узнают, как этот стандарт изменил разработку на JavaScript. Особое внимание уделяется практическим навыкам использования возможностей ES2015: деструктуризации массивов и объектов, оператору расширения, а также работе с такими типами данных, как Map, Set и Symbol. Кроме того, модуль охватывает основы npm (Node Package Manager) и `package.json`, предоставляя студентам необходимые инструменты для управления JavaScript-проектами и зависимостями.
