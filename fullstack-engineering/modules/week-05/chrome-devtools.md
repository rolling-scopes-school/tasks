# Chrome DevTools 🛠️

## Описание модуля 📚

Модуль «Chrome DevTools» подробно знакомит со встроенными инструментами разработчика в браузере Chrome. Студенты изучат основные возможности вкладки Elements для работы с HTML и CSS, вкладки Console для вывода сообщений и отладки JavaScript, вкладки Sources для анализа кода и вкладки Network для изучения сетевых запросов. Кроме того, в модуле рассматривается вкладка Application, с помощью которой можно исследовать локальное хранилище и управлять файлами cookie.

## Цели обучения 🎯

Студенты:

- Освоят вкладку Elements: научатся исследовать дерево DOM, изменять структуру HTML и проверять стили CSS.
- Научатся использовать вкладку Console для разных видов вывода данных в JavaScript и управления сообщениями консоли.
- Изучат вкладку Sources, чтобы понимать структуру веб-приложения и использовать точки останова для отладки.
- Научатся анализировать сетевые запросы на вкладке Network, включая их фильтрацию и просмотр подробной информации.
- Научатся работать с локальным хранилищем на вкладке Application.

## Теория 📖

Студентам рекомендуется изучить следующие материалы:

1. **Вкладка Elements:**
   - [Расположение элементов в дереве DOM](https://developer.chrome.com/docs/devtools/dom/#view)
   - [Исследование и изменение структуры HTML](https://developer.chrome.com/docs/devtools/dom/#content)
   - [Изменение стилей DOM-элементов](https://developer.chrome.com/docs/devtools/css/#view)
   - [Поиск стилей в исходных файлах](https://irishdotnet.dev/find-the-exact-location-of-where-a-style-is-defined-using-chrome-dev-tools)
   - [Проверка применённых стилей](https://developer.chrome.com/docs/devtools/css/issues/#css-in-computed)

2. **Вкладка Console:**
   - [Сообщения JavaScript на панели Console](https://developer.chrome.com/docs/devtools/console/)
   - [Переход из Console к исходному коду](https://developer.chrome.com/docs/devtools/console/log/#javascript)
   - [Управление сохранением сообщений](https://developer.chrome.com/docs/devtools/console/reference/#persist)

3. **Вкладка Sources:**
   - [Изучение структуры файлов веб-приложения](https://developer.chrome.com/docs/devtools/sources/#files)
   - [Точки останова и навигация по коду](https://developer.chrome.com/docs/devtools/javascript/#event-breakpoint)

4. **Вкладка Network:**
   - [Анализ сетевых запросов](https://developer.chrome.com/docs/devtools/network/#load)
   - [Фильтрация запросов и управление ими](https://developer.chrome.com/docs/devtools/network/reference/#clear)
   - [Просмотр информации о запросе](https://developer.chrome.com/docs/devtools/network/#details)

5. **Вкладка Application:**
   - [Исследование локального хранилища](https://developer.chrome.com/docs/devtools/storage/localstorage/)
