# Проект «Clean Code S1E1»

## Описание модуля 📚

Этот модуль подробно знакомит с основными принципами чистого кода, включая DRY, KISS и YAGNI. В нём подчёркивается важность написания поддерживаемого, читаемого и эффективного кода, а также рассматриваются такие важные практики, как форматирование кода, написание содержательных комментариев и правильное оформление коммитов. В ходе изучения модуля студенты получат практический опыт работы с руководствами по стилю и заложат основу для написания качественного кода профессионального уровня.

## Цели обучения 🎯

- Изучить общие принципы:
  - DRY
  - KISS
  - YAGNI
- Познакомиться с подходами к:
  - форматированию кода;
  - написанию комментариев;
  - оформлению коммитов и Pull Request;
  - использованию руководства по стилю JavaScript;
  - применению инструментов и линтеров.
- Начать осваивать практики написания чистого и читаемого кода.

## Примерное время прохождения модуля 🕒

10 часов
