# Медиазапросы 📱💻

## Описание модуля 📚

Этот модуль посвящён основам медиазапросов — важной части адаптивного веб-дизайна. Он поможет студентам получить знания, необходимые для создания адаптивных макетов веб-страниц для различных устройств. В модуле рассматриваются основные операторы медиазапросов и назначение метатега `viewport`.

## Цели обучения 🎯

Студенты:

- Изучат и поймут основы медиазапросов.
- Познакомятся с основными операторами, используемыми в медиазапросах.
- Поймут назначение метатега `viewport` и научатся его использовать.

## Примерное время прохождения модуля ⏱️

- **2,5 часа**

## Теория 📖

Студентам рекомендуется изучить следующие материалы:

1. [Полное руководство по медиазапросам CSS](https://css-tricks.com/a-complete-guide-to-css-media-queries/) - 30 минут
2. [Как работает метатег viewport](https://developer.mozilla.org/en-US/docs/Web/HTML/Viewport_meta_tag) - 15 минут
3. [Медиазапросы CSS за 7 минут](https://www.youtube.com/watch?v=yU7jJ3NbPdA) - 7 минут
4. [Как сделать сайт адаптивным для всех устройств](https://www.youtube.com/watch?v=UUjNEMXZA-k) - 30 минут
