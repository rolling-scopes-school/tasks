# Node.js

## Описание модуля 📚

Этот модуль знакомит студентов с Node.js и даёт базовое представление о серверной разработке на JavaScript. Основное внимание уделяется таким ключевым темам, как работа с путями, операции с файловой системой, а также использование потоков и конвейеров для эффективной обработки данных. В модуле рассматриваются навигация по каталогам, чтение и запись файлов и асинхронные возможности Node.js.

## Цели обучения 🎯

Студенты:

- Познакомятся с основами Node.js, включая его архитектуру и событийно-ориентированную модель.
- Научатся работать с путями: перемещаться по каталогам, определять и изменять пути к файлам для эффективного управления данными.
- Изучат операции с файловой системой Node.js, включая чтение и запись файлов, а также управление каталогами.
- Получат базовое представление об использовании потоков и конвейеров для эффективной обработки больших объёмов данных.
- Познакомятся с асинхронным программированием — одним из основных принципов Node.js, позволяющим управлять несколькими операциями одновременно.
