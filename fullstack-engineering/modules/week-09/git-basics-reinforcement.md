# Закрепление основ Git

## Описание модуля

Этот модуль предназначен для закрепления и углубления знаний студентов о Git — одном из основных инструментов современной разработки программного обеспечения. Он направлен на систематизацию уже полученных знаний, а также знакомство с более продвинутыми концепциями Git и развитие практических навыков. Студенты изучат внутренние механизмы Git, научатся эффективно управлять изменениями и использовать `.gitignore` для более удобной работы с проектами.

## В этом модуле студенты должны

1. **Закрепить навыки работы с Git**:
   - Углубить понимание Git и усовершенствовать навыки его повседневного использования.

2. **Изучить продвинутые концепции Git**:
   - **Концепции и архитектура Git**:
     - Разобраться в трёх деревьях Git.
     - Изучить хеш-значения SHA-1.
     - Узнать, как работает указатель `HEAD`.
   - **Отмена изменений**:
     - Изучить способы отмены изменений в рабочем каталоге.
     - Научиться удалять файлы из индекса, изменять последний коммит и восстанавливать предыдущие версии.
     - Научиться отменять коммиты и удалять неотслеживаемые файлы.
   - **Игнорирование файлов**:
     - Научиться эффективно использовать файлы `.gitignore`.
     - Определять, какие файлы следует игнорировать.
     - Настраивать глобальное игнорирование файлов и отслеживание пустых каталогов.
