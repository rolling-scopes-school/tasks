# Canvas API

## Описание модуля 📚

Этот модуль знакомит студентов с Canvas API. После его изучения студенты научатся использовать элемент `<canvas>` для создания двумерной графики.

## Цели обучения 🎯

В этом модуле студенты познакомятся со следующими темами:

- Методы контекста Canvas
- Рисование фигур
- Создание простых анимаций

## Примерное время прохождения модуля ⏱️

- **3 часа**

## Теория 📖

Студентам рекомендуется изучить следующие материалы:

- [Учебное руководство по Canvas — MDN](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API/Tutorial) - 2 часа
- [Учебное руководство по Canvas — W3Schools](https://www.w3schools.com/graphics/canvas_intro.asp) - 1,5 часа
- [HTML5 Canvas для начинающих — YouTube](https://youtu.be/EO6OkltgudE) - 15 минут
- [Рисование с помощью HTML5 Canvas для начинающих — YouTube](https://youtu.be/83L6B13ixQ0) - 16,5 минуты
- [Анимация с помощью HTML5 Canvas для начинающих — YouTube](https://youtu.be/yq2au9EfeRQ) - 32 минуты
