# DOM API 🌐

## Описание модуля 📚

В этом разделе курса участники изучат основные аспекты объектной модели документа (DOM), объектной модели браузера (BOM) и объектной модели CSS (CSSOM). Они получат практические навыки навигации по DOM и управления его элементами, научатся работать с CSS с помощью JavaScript, а также разберутся со свойствами и поведением веб-документов.

## Цели обучения 🎯

Студенты изучат:

- Основные концепции и возможности DOM, BOM и CSSOM.
- Способы навигации по DOM и использования селекторов для поиска элементов.
- Методы работы с типами узлов и тегами, содержимым элементов, атрибутами и свойствами.
- Способы изменения элементов, применения стилей и управления классами с помощью JavaScript.
- Работу с размерами и прокруткой элементов, размерами окна браузера и координатами элементов.

## Примерное время прохождения модуля ⏱️

- **2 часа**
