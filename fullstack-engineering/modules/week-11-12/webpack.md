# Webpack

## В этом модуле студентам необходимо:

- Знать и понимать назначение Webpack и процесса сборки проекта
- Иметь общее представление о файле `webpack.config`
- Уметь работать с готовой конфигурацией Webpack

### Содержание

1. История
   - История развития
   - Модули и обычные файлы: Gulp и Webpack
   - Модули и зависимости
   - Разделение кода
   - Webpack и AMD, CommonJS, ES6
   - Производительность
2. Что такое Webpack?
   - Что такое Webpack?
   - Установка `webpack` и `webpack-cli`
   - Запуск Webpack
   - Запуск сборки с использованием `webpack.config`
   - Использование npm-скриптов для сборки
3. `webpack.config`
   - `entry`
   - `output`
   - `plugins`
   - `loaders`
   - `preLoaders`
   - `devtool`
4. Загрузчики Webpack
   - Что такое загрузчик?
   - Настройка `babel-loader` для проекта
   - Использование `@babel/preset-env`
   - Использование `@babel/preset-react`
5. Загрузка ресурсов
   - Загрузка CSS с помощью Webpack
   - Загрузка изображений с помощью Webpack
   - Использование `webpack-dev-server`
6. Разделение кода с помощью Webpack
   - Что такое разделение кода?
   - Добавление нескольких точек входа
   - Оптимизация с помощью `SplitChunks`
   - Использование `HtmlWebpackPlugin`
   - Подготовка кода к продакшену
