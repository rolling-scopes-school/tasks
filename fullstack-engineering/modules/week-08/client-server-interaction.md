# Обзор клиент-серверного взаимодействия

## Описание модуля 📚

Этот модуль представляет собой подробный обзор клиент-серверного взаимодействия. В нём рассматриваются основные способы взаимодействия клиента с сервером, особенности протоколов HTTP и HTTPS, CORS, а также развитие версий HTTP. Дополнительные материалы помогут глубже разобраться в работе сетей, сетевых моделях, шифровании, SSL-сертификатах и протоколах HTTP.

## Цели обучения 🎯

Студенты:

- Изучат способы взаимодействия клиента с сервером.
- Рассмотрят протокол HTTP, включая методы, коды состояния, заголовки и тело сообщения.
- Познакомятся с протоколом HTTPS.
- Разберутся с CORS (Cross-Origin Resource Sharing — совместное использование ресурсов между разными источниками).
- Познакомятся с версиями HTTP 1.x, 2.x и 3.x.
