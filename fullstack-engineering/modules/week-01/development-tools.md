# Основы Chrome DevTools, VS Code и работы интернета

## Цели модуля

В рамках этого модуля студентам необходимо познакомиться с:

- принципами и особенностями работы браузеров;
- возможностями Chrome DevTools (Styles и Element Inspector);
- редактором VS Code:
  - настройкой среды разработки;
  - расширениями;
  - консолью;
- основными командами терминала.

## Приблизительное время прохождения модуля

4 часа
